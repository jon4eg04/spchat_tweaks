# SpicyChat Tools

Одна установка Tampermonkey: 11 основных функций и дополнительная настройка быстрого выбора моделей. Исходники разделены по функциям; готовая сборка обновляется по постоянной ссылке.

**[Установить SpicyChat Tools](https://raw.githubusercontent.com/jon4eg04/spchat_tweaks/main/dist/spicychat-tools.user.js)** · **[Инструкция по переезду](docs/MIGRATION.md)**

Первый запуск открывает настройки и **не включает функции автоматически**. Это позволяет перенести данные, пока старые скрипты ещё установлены.

## Переезд в двух словах

1. В Tampermonkey → **Утилиты** экспортируй ZIP со старыми скриптами, включив **данные / хранилище скриптов**. Сохрани архив у себя.
2. Установи новый комплект по ссылке выше и открой привычный адрес SpicyChat в том же профиле браузера. Нажми **SC Tools**, если окно не открылось само.
3. Выбери ZIP в разделе переноса. Проверь, что найдены все 11 основных модулей, и нажми **Перенести данные**. Старый `Hide selected model blocks` распознаётся дополнительно, если есть в архиве.
4. Отключи старые 11 скриптов в Tampermonkey, отметь подтверждение в настройках нового комплекта и нажми **Запустить комплект**.
5. Закрой или перезагрузи остальные вкладки SpicyChat. Проверь закладки, тексты, настройки чатов, пересказ и озвучку. Старые скрипты пока сохрани выключенными.

Архив обрабатывается локально. На GitHub и на серверы он не отправляется. Адреса и токены обработчиков берутся из старых скриптов и сохраняются только в хранилище нового userscript. Настройки эмодзи и чатов читаются из локальных данных сайта — поэтому важно использовать тот же профиль и тот же адрес (`www` и адрес без `www` имеют разные хранилища).

## Возможности

| Модуль | Исходная версия |
|---|---|
| Emoji Picker | 1.3.0 |
| Быстрое удаление сообщений | 2.2.0 |
| Время сообщений | 1.2.0 |
| Галерея изображений диалога | 1.1.2 |
| Дерево чатов | 1.3.0 |
| Закладки сообщений | 1.3.0 |
| Кнопки изображения и Suggest Reply | 2.1.0 |
| Настройки для каждого чата | 1.3.1 |
| Пересказ диалога через OpenAI | 1.2.0 |
| Сохранённые тексты | 1.3.0 |
| Эмоциональная озвучка Inworld | 1.0.0 |
| Скрытие ненужных моделей (дополнительный модуль) | на основе 1.1 |

Каждая функция отключается в общих настройках. Переключатели применяются после перезагрузки страницы. Настройки открываются кнопкой **SC Tools** на сайте или пунктом **SpicyChat Tools — настройки и перенос** в меню Tampermonkey.

Начиная с версии 1.0.1 модуль **Скрытие ненужных моделей** убирает строки `Qwen3 235B 2507` и `Codex 24B` из меню. Он включается по умолчанию при обновлении существующего комплекта; переносить данные повторно не нужно. Если отдельный `Hide selected model blocks` ещё установлен, отключи его и перезагрузи страницу.

В версии **1.0.6** штатное быстрое меню и **Настройки для каждого чата → Ответ и модель** используют общий список: **Deepseek V4 Pro → Qwen Plus Character → Glam 5.1 → MiMo V2.6 Pro**. В настройках чата также остаётся «Как выбрано на сайте». Для MiMo используется подтверждённый идентификатор `mimo-v26-pro`.

Быстрое меню настраивает модуль **Скрытие ненужных моделей**. В версии **1.0.7** MiMo вызывает тот же штатный обработчик, что и соседние модели: сайт сохраняет выбор, показывает уведомление и закрывает меню. При повторном открытии галочка стоит на выбранной модели. Полный список при этом не открывается. Персональная настройка модели чата, как и раньше, имеет приоритет над выбором на сайте.

Для добавленной строки используется узкий адаптер проверенного React-контракта `model / activeModel / clickHandler`; имена компонентов не зашиты. Если сайт изменит этот контракт, добавленная строка станет недоступна с пояснением при наведении, без открытия других окон и без подмены галочки. Штатные строки продолжают использовать свои обработчики.

Сохранённые ранее настройки Glam 4.6 не удаляются: только в таком чате старое значение показывается с пометкой «сохранено ранее», пока пользователь не выберет другую модель.

Пересказ и озвучка используют собственные серверные обработчики пользователя. Серверный код и учётные данные не входят в этот публичный репозиторий. Если такие обработчики не настроены, соответствующие функции можно выключить.

## Быстрые команды в 1.0.8

В **SC Tools → Быстрые команды** добавляй команды с названием и текстом, редактируй и удаляй их. Библиотека общая для всех чатов; изменения сохраняются сразу в Tampermonkey. Готовых текстов в публичном скрипте нет: библиотеку заполняет пользователь.

В **«+ → Постоянная команда»** остаётся ручное поле и появляются галочки с названиями команд. Отметь несколько нужных и нажми **Сохранить**: выбор относится только к текущему диалогу. Каждая отмеченная команда и ручной текст отправляются **отдельной `/cmd`**, например:

```text
Сообщение пользователя

/cmd Ручная команда

/cmd Текст первой отмеченной команды

/cmd Текст второй отмеченной команды
```

Сначала идёт ручная команда, затем выбранные из библиотеки в порядке добавления. Редактирование названия/текста сохраняет галочку; новый текст используется со следующего запроса. Удаление команды убирает её из всех диалогов. **Удалить ручную** очищает только ручной текст. Чтобы отключить всё для чата, очисти поле, сними все галочки и сохрани. Закрытие окна без сохранения оставляет прежний выбор.

Библиотека и галочки хранятся в Tampermonkey и входят в JSON-копию SC Tools. Прежняя ручная команда остаётся в прежнем локальном хранилище сайта и подхватывается без повторного переноса. Обновление сохраняет остальные данные и настройки.

## Исправления запуска в 1.0.6

Запуск окна SC Tools, функций у поля ввода и скрытия моделей больше не зависит от одного события DOMContentLoaded: добавлена резервная проверка готовности страницы. Это покрывает случай, когда ранние функции уже работают, а остальная часть комплекта не запустилась. Ранние сетевые перехватчики по-прежнему устанавливаются сразу.

Обновление сохраняет данные; повторный перенос не нужен.

## Сверка исходных функций в 1.0.5

Полная [сверка всех одиннадцати модулей с исходниками](docs/PARITY.md): сохранённые функции, конкретные отличия и проверки. Стили и пользовательские алгоритмы сохранены. Исправлена интеграция пункта пересказа с остальными меню и возвращены инлайн-стили при клонировании штатного пункта. Снято отсутствовавшее в исходниках ограничение фреймов.

Проверки перед публикацией выполняются в Chromium и Firefox, включая одновременное включение всех модулей. Пересказ и озвучка проверяются на подставных ответах без запросов к пользовательским обработчикам.

## Исправления интерфейса в 1.0.4

Исправлено ложное распознавание кнопки изображения у поля ввода как открытого меню «+». Пункты «Ответ и модель» и «Постоянная команда» добавляются только в настоящее меню; копий рядом с полем нет. Окна настроек и CMD закрываются по клику снаружи и Escape. Стили исходных скриптов сохранены.

Браузерные проверки теперь обязательны в GitHub Actions перед публикацией установочного файла. Они включают штатную кнопку изображения вне меню, закрытие окон и отсутствие дублей.

Обновление сохраняет данные и настройки; повторный перенос не нужен.

## Исправления интерфейса в 1.0.3

- «Сохранить сообщение» и «Добавить в закладки» появляются в меню сообщения независимо от включения быстрого удаления и сохранённых текстов.
- Меню сообщений, чата и «+» распознаются как рядом с кнопкой, так и в отдельном слое страницы. Поддерживаются пункты без прежних `aria-label` и элементы `role="menuitem"`.
- Настройки токенов, модели и постоянной `/cmd`, лампочка Suggest Reply и создание изображения используют обновлённый поиск штатных действий.
- Исправлено смешивание служебных классов галереи и закладок; ошибка окна SC Tools больше не блокирует запуск функций у поля ввода.

Обычное обновление до 1.0.3 сохраняет данные и переключатели модулей; повторный перенос не нужен. Пересказ и Inworld в этой проверке не менялись.

## Обновления

В сборке прописаны постоянные `@updateURL` и `@downloadURL`. В настройках Tampermonkey включи проверку обновлений и выбери интервал. Для немедленной проверки используй **Проверить обновления скриптов**, затем перезагрузи страницу SpicyChat.

Локальные адреса, токены и сохранённые данные остаются в Tampermonkey при обычном обновлении. `@connect *` нужен для пользовательских адресов, неизвестных во время сборки. При первом запросе Tampermonkey может попросить разрешить подключение к настроенному серверу.

## Разработка

Нужен Node.js 24. Внешние зависимости для сборки и основных тестов не требуются.

```bash
npm run check
```

| Путь | Назначение |
|---|---|
| `src/modules/*.js` | По одному файлу на каждую функцию |
| `src/modules.json` | Каталог функций, исходные идентификаторы и ключи данных для переноса |
| `src/core/native-models.js` | Прямое подключение к штатному выбору модели |
| `src/core/quick-commands.js` | Библиотека команд, выбор по чатам и сохранение с откатом |
| `src/core/command-manager.js` | Добавление, правка и удаление команд в SC Tools |
| `src/core/models.js` | Общий список моделей для двух меню |
| `src/core/dom.js` | Общий поиск штатных меню и привязка к нужному сообщению |
| `src/core/settings.js` | Локальные настройки комплекта и обработчиков |
| `src/core/migration.js` | Планирование переноса, импорт, экспорт, откат ошибок |
| `src/core/zip.js` | Локальное чтение штатного ZIP-экспорта Tampermonkey |
| `src/core/ui.js` | Общее окно настроек и переноса |
| `src/main.js` | Порядок запуска и изоляция ошибок инициализации |
| `scripts/build.mjs` | Сборка одного userscript без сетевых зависимостей |
| `dist/` | Автоматически созданные установочные файлы; вручную не редактировать |

Для релиза: измени нужный модуль, увеличь версию `package.json` командой `npm version patch --no-git-tag-version`, выполни `npm run check`, закоммить и отправь изменения в `main`. GitHub Actions повторит проверки и при необходимости запишет обновлённый `dist/`. Проверка версии останавливает публикацию изменений исходников без увеличения версии.

Тесты проверяют ZIP, типы данных Tampermonkey, перенос всех 11 модулей, сохранение выключенных функций, локальных настроек и токенов, защиту существующих данных, откат неудачного импорта, повторный экспорт/импорт и сетевые перехватчики настроек чатов в окружении с sandbox. Тесты используют вымышленные данные. Реальный интерфейс SpicyChat после обновлений сайта может потребовать адаптации селекторов.

Дополнительная браузерная локальная проверка окна настроек, ZIP-переноса и запуска всех модулей на локальном макете сайта:

```bash
npm install --no-save --package-lock=false playwright@1.62.1 react@18.3.1 react-dom@18.3.1
npx playwright install chromium firefox
node tests/browser-smoke.mjs
node tests/feature-ui.mjs
TEST_BROWSER=firefox node tests/browser-smoke.mjs
TEST_BROWSER=firefox node tests/feature-ui.mjs
```

Для уже установленного браузера можно задать `CHROMIUM_EXECUTABLE`, а для внешней установки Playwright — `PLAYWRIGHT_PACKAGE`. Проверка `feature-ui.mjs` выполняет сохранение/вставку текстов, эмодзи, закладки, настройки токенов/модели/CMD и перехват запроса, кнопки генерации, галерею, дерево чатов, время, удаление и повторную отправку. Отдельно проверяются закрытие по клику снаружи и Escape, отсутствие пунктов меню возле поля ввода со штатной кнопкой изображения, независимость модулей, меню в отдельных слоях и внутри сообщений, повторное использование меню и перемонтирование поля ввода. Пересказ и озвучка проверяются на подставных обработчиках, включая кеш и отмену. Выбор модели дополнительно проверяется на настоящем React 18: сохранение, уведомление, закрытие меню, галочка при повторном открытии и обновление существующих строк. Проверки подменяют сетевые запросы тестовыми ответами и не открывают авторизованный аккаунт.
