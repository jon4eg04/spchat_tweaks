# Переезд с 11 отдельных скриптов

## 1. Сохрани резервную копию

Открой панель управления Tampermonkey → **Утилиты** → экспорт в **ZIP**. Включи **данные скриптов / хранилище / Script storage**; точное название зависит от языка и версии расширения. В экспорт должны попасть сами 11 скриптов, их настройки и сохранённые данные. Можно экспортировать все установленные скрипты: импортёр выберет только знакомые модули SpicyChat.

Для модулей с данными в архиве будут файлы с окончанием `.storage.json`, рядом с `.user.js` и `.options.json`. Если флаг данных выключен, получится архив с кодом, но без закладок и текстов. При отсутствии файлов данных новый комплект покажет предупреждение. Не продолжай переезд, пока не проверишь экспорт.

Оставь ZIP у себя: он содержит личные данные, а также может содержать адреса и токены из старого кода. Для импорта его не нужно присылать кому-либо или загружать на GitHub.

## 2. Установи новый комплект

Открой [установочный файл](https://raw.githubusercontent.com/jon4eg04/spchat_tweaks/main/dist/spicychat-tools.user.js) и подтверди установку в Tampermonkey.

Открой SpicyChat **в том же браузерном профиле и по тому же адресу**, которым пользовался раньше. Адрес без `www` и адрес с `www` имеют разные локальные хранилища. На этом этапе старые скрипты могут оставаться включёнными: новый комплект до подтверждения запуска показывает только свои настройки.

Если окно не открылось, нажми **SC Tools** в правом нижнем углу сайта или пункт настроек в меню расширения.

## 3. Перенеси данные

В разделе **Переезд со старых скриптов** нажми **Выбрать резервную копию** и выбери ZIP. Дождись таблицы предварительного просмотра.

- Должно быть найдено **11 из 11 основных** модулей. Отдельный старый `Hide selected model blocks` распознаётся как дополнительный модуль, но его отсутствие не мешает переносу.
- Проверь состояния «Вкл.» и «Выкл.»: они будут перенесены.
- «Данные / сайт» — число записей хранилища, а не число отдельных закладок или сообщений.
- Для пересказа и озвучки должны подхватиться параметры обработчиков. Поля токенов скрыты; значения остаются локальными.
- При первом переносе оставь **Заменять уже существующие данные** выключенным. Это защищает данные нового комплекта при случайном повторном импорте.

Нажми **Перенести данные** и дождись сообщения об успешном завершении. Старые установки и их данные импортёр не удаляет. При ошибке записи предусмотрен откат; исходный ZIP остаётся резервной копией.

## 4. Переключись на новый скрипт

В панели Tampermonkey **отключи все старые 11 скриптов SpicyChat**, а также `Hide selected model blocks`, если он установлен, но пока не удаляй их. Новый **SpicyChat Tools** оставь включённым.

Вернись к настройкам, отметь **Я отключил старые скрипты SpicyChat…** и нажми **Запустить комплект**. Эта вкладка перезагрузится. Остальные вкладки SpicyChat тоже перезагрузи или закрой: в старых открытых страницах предыдущий код продолжает работать до перезагрузки.

## 5. Проверь результат

Открой несколько привычных диалогов и проверь закладки, сохранённые тексты, названия веток, лимит ответа, модель и постоянную команду. Проверь недавние эмодзи. Если используешь пересказ и озвучку, вызови их; при запросе Tampermonkey разреши подключение к собственному обработчику.

После проверки можно оставить старые скрипты выключенными как запасной вариант. В новом окне есть **Скачать копию настроек и данных** — она сохраняет JSON со всеми данными комплекта, включая локальные настройки сайта и параметры обработчиков. Такой JSON тоже можно импортировать через **Выбрать резервную копию**.

## Что откуда переносится

| Данные | Источник |
|---|---|
| Включение/отключение каждой функции | Настройки старых скриптов в ZIP |
| Закладки, дерево чатов, сохранённые тексты | Хранилища соответствующих скриптов в ZIP; локальное хранилище как резервный источник |
| Сохранённые даты сообщений и кеш пересказов | Хранилища соответствующих скриптов в ZIP |
| Лимиты ответа, модели и постоянные команды чатов | Локальное хранилище сайта в этом профиле |
| Недавние и часто используемые эмодзи | Локальное хранилище сайта в этом профиле |
| Адреса и токены двух обработчиков | Литеральные настройки в коде старых скриптов из ZIP |
| История чатов и изображения SpicyChat | Продолжают храниться в самом сервисе; этот переезд их не изменяет |

Индивидуальные технические переопределения Tampermonkey вроде ручных `@match`, `@run-at` и выданных разрешений не копируются: у единого скрипта свои общие метаданные и разрешения.

## Если нужно вернуться

В меню нового комплекта нажми **Приостановить комплект**. Затем отключи **SpicyChat Tools** в Tampermonkey, включи прежние скрипты и перезагрузи все вкладки SpicyChat. Их прежние GM-хранилища не менялись при импорте. Новые закладки и тексты, добавленные уже в едином комплекте, автоматически обратно в старые скрипты не переносятся; сначала скачай резервную копию нового комплекта.
